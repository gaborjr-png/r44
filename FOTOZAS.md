# Fotózási terv

A jelenlegi fotók egy része generált hatású. Egy fél napos profi fotózással az egész oldal hitelesebb lesz.
A fájlokat **ugyanazzal a névvel** kell a `src/assets/img/` mappába tenni (WebP, hosszabbik oldal kb. 1600–2000 px, 150–350 kB),
utána `python3 src/build.py`.

| Fájl | Hol jelenik meg | Mit fotózzunk |
|------|-----------------|---------------|
| `csarnok.webp` | Főoldal nyitókép, Géppark, Karrier | A csarnok hosszában, gépsorral, tiszta padló, reggeli fény, ember a háttérben |
| `star-sr16.webp`, `star-sr32.webp` | Tevékenységek, Géppark | STAR automaták közelről, nyitott ajtó, forgácsolás közben, hűtőfolyadékkal |
| `maras-munka.webp` | Tevékenységek (marás), Géppark | Akira Seiki / Bridgeport megmunkálóközpont munka közben, szerszám közeli |
| `alkatreszek-maras.webp` | Főoldal (bemutató) | Kész alkatrészek sorban, fekete háttér, oldalfény, sárgaréz + alumínium |
| `meroszoba.webp`, `cmm.webp` | Minőségügy, Főoldal | Klimatizált mérőszoba; mérőgép mérés közben, kolléga a monitornál |
| `szallitas.webp` | Főoldal, Tevékenységek | Csomagolt, címkézett alkatrészek raklapon, KLT-ládákban |
| `telephely*.webp` | Főoldal, Rólunk, Kapcsolat | Drónfotó naplementében; homlokzat logóval (ellenőrizni: ne legyen rajta más cég felirata) |
| `munkasszallo.webp` | Karrier | Munkásszálló kívülről + 1–2 belső fotó (szoba, konyha) |
| `csapat.webp` (új) | Rólunk / Karrier | Csapatfotó a csarnokban, munkaruhában – ez adja a legtöbb bizalmat |

Tipp: a fotós kapjon egy listát a gépekről (Géppark oldal), és kérjünk tőle 16:9 és álló (4:5) változatot is.
